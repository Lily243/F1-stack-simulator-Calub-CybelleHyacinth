**Course:** CC104 - Data Structures

## Description

This project contains the starter files for a Stack Data Structure Simulator. It uses HTML to structure the webpage, CSS and Bootstrap to style the interface, and JavaScript with jQuery to manage and display the stack data.

The simulator demonstrates the Last In, First Out (LIFO) principle of a stack. The starter interface includes Push, Pop, Peek, and Clear buttons.

## Starter Repository

Original repository: https://github.com/Jackson-Soriano/e26_temp

## Files Included

- `index.html` — Defines the webpage structure.
- `style.css` — Controls the custom appearance of the webpage.
- `stack.js` — Contains the JavaScript stack implementation and initial display logic.
